# 디자인

> 이 문서가 답하는 질문: 어떻게 보이는가. 색·글꼴·간격은 숫자로. 화면 만들 때 `@docs/design.md`.
> 토큰의 원본은 `frontend/src/app/globals.css` `@theme`. 여기와 어긋나면 globals.css를 따르고 이 문서를 고친다.

## 원칙

- **홈에서 스크롤 없이 전부.** 첫 화면 안에 검색·기능·실시간 매물이 다 들어간다. 화면 높이에 맞춰 늘고 줄어드는 레이아웃(`h-dvh` + flex), 고정 px 높이로 넘치지 않게.
- 반응형 하나의 페이지. 데스크톱(≥1024)과 모바일(<768)이 같은 컴포넌트를 다른 배치로.
- 다크 모드 없음 (1단계).
- 카드 남발 금지. 구분선과 여백으로 나누고, 카드(테두리+흰 배경)는 폼·타일·메뉴에만.
- 중앙 큰 제목·히어로·플로팅 버튼 없음. 기능부터 바로.
- 아이콘은 선 아이콘(stroke 1.8, 24 viewBox), 인라인 SVG. 이모지 금지. 예외: 판매·구매 아이콘(홈 아이콘 줄·헤더 앱 메뉴)은 2톤 일러스트, 앱 메뉴 버튼(∷)은 채운 점 9개 (아래 규격).

## 글꼴

| 역할 | 글꼴 | 굵기 |
|---|---|---|
| 본문·제목 | Noto Sans KR (next/font/google) | 400 / 500 / 700 |
| 숫자·가격·모델명 | IBM Plex Mono, `tabular-nums` | 500 / 600 |

크기 단계 (px): 11 캡션 · 12 보조 · 13 본문(목록) · 14 본문 · 15 강조 · 17 검색 입력 · 18 로고 · 20 제목.
줄 간격 1.5. 한글 `word-break: keep-all`.

## 간격·모양

- 간격 스케일: 4, 6, 8, 10, 12, 16, 20, 24, 28.
- 페이지 옆 여백: 데스크톱 24, 모바일 16.
- 모서리: 입력·버튼·카드 6, 타일 10, 아이콘 원 12, 로고 마크 6.
- 테두리 1px `line`. 검색창만 2px `primary`.
- 그림자 없음 (시안 뷰어 제외).

## 브레이크포인트

| 이름 | 폭 | 홈 배치 |
|---|---|---|
| 모바일 | < 768 | 세로 1열. 하단 탭바. 문구 + 검색창 + 판매·구매 아이콘 줄(두 줄)을 가운데 |
| 태블릿·데스크톱 | ≥ 768 | 문구 + 검색창 + 판매·구매 아이콘 줄(최대 폭 880)을 화면 가운데(조금 위) — 구글 첫 화면처럼. 같은 아이콘이 헤더 앱 메뉴(∷)에도 있다 (2026-10-19 둘 다). 실시간 목록·구매대행·경매 자리는 없음. 스크롤 없음 |

## 컴포넌트 규격

**타일 큐 (화면 분할)** 모든 화면 전환을 하나의 큐로 (스펙 `docs/superpowers/specs/2026-10-01-tile-queue-design.md`). 폭 768 이상만 분할: 1칸 전체 → 2칸 1:1 → 3칸 왼쪽 1/2 · 오른쪽 위 1/4 · 오른쪽 아래 1/4 (읽는 순서 = 오래된 순서, 새 칸은 오른쪽 아래, 가득 차면 왼쪽 칸이 빠지고 당겨짐). 칸 사이 구분은 없음(각 칸 배경). 2칸 이상이면 모든 칸 오른쪽 위에 닫기(28 원, 흰 배경, 1px `line`, 호버 `primary` 테두리). 로고는 항상 홈 전체화면.

**헤더** 높이 56 (모바일 52). 배경 `primary`, 글자 흰색, 내비 `on-primary`. 로고 = 초록 사각(28, radius 6) + 흰 칩 아이콘 + "커널마켓" 18/700. 오른쪽 앱 메뉴(∷) · 로그인(초록 버튼 60×34). 모바일은 항목 사이 간격 12(데스크톱 28) — 360 폭에서도 로그인 버튼이 잘리지 않게. 회원가입 버튼은 없다 — 로그인 화면의 개인·기업 탭에서 가입 (2026-10-13). 로그인은 **별도 페이지**로 이동 (모달 아님). 헤더는 루트 레이아웃에 한 번만 두고, 로그인·가입 화면과 분할(2·3칸) 상태에서도 같은 링크를 유지한다 (로그인 상태면 그 자리에 사용자 메뉴).
- 사용자 메뉴: 닉네임 첫 글자 원 36(누르는 영역 44), 15/700. 개인 = `primary-soft` 면 + `primary` 글자, 사업자 = `primary-dark` 면 + 흰 글자 + 흰 테두리 2(보라 헤더 위에서 구분). 누르면 오른쪽 정렬 메뉴(폭 224, 흰 배경 + 1px `line`, 그림자 없음): 맨 위 닉네임 14/700 말줄임 + 배지(높이 20, radius 5, 11/600 — 개인 `primary-soft`/`primary-dark`, 사업자 `primary-dark`/흰색) · 구분선 · 마이페이지 · 내 판매글 · 받은 구매요청 · 내 구매목록 · 구분선 · 로그아웃. 로그아웃 실패 시 메뉴를 닫지 않고 아래에 `down` 12 문구. 이메일·전화·실명은 보이지 않는다.

**마이페이지** (`/my`, 로그인 필요) 다른 폼 화면과 같은 틀(최대 폭 720, 제목 20/700 + 보조 13, 흰 카드 안쪽 20/24). 카드 위쪽 사용자 칸: 이니셜 원 56 + 닉네임 17/700 + 배지, 아래 `line-2` 구분선. 그 아래 바로가기 카드 셋(내 판매글·받은 구매요청·내 구매목록): 1px `line` + radius 6, 안쪽 16/14, 제목 15/700 + 설명 13 `ink-2`, 호버 `primary` 테두리 + `bg` 배경, 칸 폭 576 이상이면 두 칸.

**내 판매글** (`/my/listings`, 로그인 필요) 검색 결과 화면(아래)과 같은 틀·폭(최대 1200)·검색창·필터 바·표/카드·[더 보기]. 다른 점: 제목 "내 판매글" 20/700 한 줄이 위에, 체크박스·[견적 요청]·[구매] 없음, 거래상태 기본값 "전체", 표 맨 오른쪽에 [수정] 열(폭 80, 오른쪽 `sticky`, 왼쪽 1px `line-2`, 버튼 높이 28 outline `primary`). 글이 하나도 없으면 "등록한 판매글이 없어요" + [판매상품 등록하기]. 좁은 카드(칸 폭 576 미만)는 카드 아래 [수정] 버튼이 수정 화면으로 간다.

**행 안 수정** [수정]을 누르면 목록 대신 그 행의 편집기만 보인다(다른 행·[더 보기] 숨김, 보던 스크롤 위치는 끝나면 되돌림). 위쪽에 "<상품명> 수정 중" + [저장](채움 `primary`)·[취소](outline `line`)·"바꾼 내용이 없어요"(`ink-3` 12), 그 아래 표 한 행이 입력칸으로: 상품명·상품번호·제조사(입력 높이 34, 13), 제조일(date), 상품상태(구간 select), 보증기간(개월 select), 불량지원(select), 칸 아래 `down` 11 오류. 상품설명·데이터시트·사진·대체품·테스트리포트·정품인증서는 "입력됨/없음" 버튼(높이 34, 선택되면 `primary-soft`, 오류면 `down` 테두리)이고, 누르면 표 아래에 흰 카드(1px `line`, 안쪽 16)로 그 항목 폼만 뜬다(설명 textarea 4줄·200자, 파일은 업로더, 사진은 4장 업로더). 한 번에 하나. 업로드 중엔 [저장] 비활성. 열 순서·폭은 검색 표와 같되 입력칸이 들어가게 제조일·상품상태는 조금 넓다.

**내 구매목록** (`/my/purchases`, 로그인 필요) 표/카드·[더 보기]는 내 판매글과 같은 틀. 행: 거래ID·상품명·판매자 닉네임·주문량·단가·금액·납품희망일·상태, `구매요청` 행에 [거래완료]·[취소](각각 확인 창). 409 면 목록을 다시 읽는다.

**받은 구매요청** (`/my/sales`, 로그인 필요) 같은 목록 컴포넌트(`TradeList`)의 판매자용: 구매자 닉네임·요청사항, `구매요청` 행에 [취소]만. `?reg=` 면 그 매물만 + [전체 보기]. 내 판매글의 "구매요청 N건"(0이면 "-")이 여기로 연다. 세부는 `docs/superpowers/specs/2026-10-15-purchase-design.md`.

**검색** 높이 56 (모바일 44). 흰 배경, 2px `primary` 테두리, radius 8. 왼쪽 카테고리 `select`(112px, `primary-soft` 배경 — 카테고리 마스터 미정으로 보류, 지금은 숨김) · 돋보기 · 입력 17px · 오른쪽 검색 버튼(104px, `primary`, 흰 16/700). 아래 "인기 검색" 텍스트 링크 한 줄, 중앙 정렬. 최대 폭 880. 위에 한 줄 문구(20/700, 모바일 17, 중앙). 히어로가 아니라 한 줄이 전부.

**홈 판매·구매 아이콘** (`QuickMenu`, 검색창 아래. 2026-10-13 에 앱 메뉴로 옮겼다가 2026-10-19 다시 — 앱 메뉴와 둘 다) 카드·글씨 없이 아이콘만. 두 묶음을 한 줄에 (모바일은 두 줄). 묶음 앞 배지: 높이 24, radius 5, 12/700, 판매 `primary`·구매 `green` 채움 + 흰 글자.
- 아이콘은 앱 메뉴와 같은 그림. 이름은 툴팁(`title`)·`aria-label`로만. 호버 배경 radius 12: 판매 `primary` 10%, 구매 `green` 12%.
- 항목은 앱 메뉴와 같다. 판매상품 등록은 드롭다운(직접 입력 · 파일 추가 엑셀/PDF/이미지, 흰 배경 + 1px `line`, 그림자 없음). 파일 검사 결과는 아이콘 줄 아래 한 줄 (오류 `down`, 안내 `ink-2`, 닫기 ×).

**헤더 앱 메뉴(∷)** (`AppLauncher`, 2026-10-13, 구글 앱 메뉴처럼. 홈 아이콘 줄과 같은 항목) 헤더 오른쪽 로그인·사용자 메뉴 왼쪽. 버튼은 점 9개 아이콘 22, 누르는 영역 44 원, 이름 "판매·구매 메뉴"(사용자 메뉴 "내 메뉴"와 구분), `on-primary` → 호버 흰색 + 흰 10% 원.
- 메뉴: 오른쪽 정렬, 폭 304, 흰 배경 + 1px `line`, radius 10, 안쪽 12, 그림자 없음. 묶음 2개(판매·구매)를 위아래로, 사이 `line-2` 선. 묶음 머리 배지(높이 20, radius 5, 11/700, 판매 `primary`·구매 `green` 채움 + 흰 글자).
- 칸: 3열 격자, 아이콘 40 위 + 이름 12 아래(최대 2줄, 가운데). 호버·포커스 배경 radius 8: 판매 `primary` 10%, 구매 `green` 12%.
- 아이콘은 사용자가 준 일러스트(`frontend/public/icons/quick/*.png`, 배경 투명 160px)와 직접 그린 엑셀 대량구매 SVG 그대로. 판매는 보라·구매는 초록 한 톤.
- 판매 4: 판매상품 등록(누르면 판매 격자 아래에 등록 방법이 펼쳐짐 — `bg` 바탕 목록: 직접 입력 · 파일 추가 엑셀/PDF/이미지. 옆 하위 메뉴는 같은 줄 칸을 가려서 안 씀) · 판매상품 다량 등록(엑셀 선택창 바로) · 판매정보 추가 등록 · 판매 견적 조정. 구매 3: 상품검색·견적 요청 · 견적 확인 · 엑셀 대량구매.
- 링크를 고르면 메뉴가 닫히고 타일 큐 규칙대로 열린다. 파일 고르기는 메뉴를 닫지 않고 결과를 메뉴 맨 아래 한 줄(`bg` 바탕, 12, 오류 `down`, 안내 `ink-2`, 닫기 ×)로 알린다.

**검색 결과 화면** (`/search`, 스펙 `docs/superpowers/specs/2026-10-01-search-results-design.md`) 칸 폭 기준(`@container`)이라 타일 칸이 768 미만이면 모바일 배치(접힌 필터·작은 검색창). 단 결과 표↔카드만 기준이 576 — 반반 분할(칸 720 안팎)에서도 표가 가로로 펼쳐진다 (사용자 지시). 홈 | 결과 같은 분할은 화면이 아니라 타일 큐 엔진이 맡는다 (decisions.md 2026-10-01 타일 큐). 결과 영역 최대 폭 1200, 스크롤 허용 (홈 "스크롤 없이" 원칙의 예외). 위에서부터:
- 범위 전환 [전체 | 내 판매] (2026-10-19): 왼쪽 정렬, 높이 34, 1px `line` radius 6, 칸 사이 `line` 선, 선택 칸 `primary-soft`/`primary-dark` 500 (거래상태 토글과 같은 모양). 검색어·필터는 유지하고 `mine=1` 만 바꾼다. 내 판매는 로그인 필요(비로그인이면 로그인 화면). 내 판매글 화면(`/my/listings`)에는 없다.
- 검색창: 홈 검색창 모양, 높이 48 (모바일 44). 왼쪽 select는 검색 구분 전체/상품명/제조사 (112, 모바일 72). 인기 검색 줄 없음.
