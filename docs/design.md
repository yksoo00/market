# 디자인

> 이 문서가 답하는 질문: 어떻게 보이는가. 색·글꼴·간격은 숫자로. 화면 만들 때 `@docs/design.md`.
> 토큰의 원본은 `frontend/src/app/globals.css` `@theme`. 여기와 어긋나면 globals.css를 따르고 이 문서를 고친다.

## 원칙

- **홈에서 스크롤 없이 전부.** 첫 화면 안에 검색·기능·실시간 매물이 다 들어간다. 화면 높이에 맞춰 늘고 줄어드는 레이아웃(`h-dvh` + flex), 고정 px 높이로 넘치지 않게.
- 반응형 하나의 페이지. 데스크톱(≥1024)과 모바일(<768)이 같은 컴포넌트를 다른 배치로.
- 다크 모드 없음 (1단계).
- 카드 남발 금지. 구분선과 여백으로 나누고, 카드(테두리+흰 배경)는 실시간 목록·타일에만.
- 중앙 큰 제목·히어로·플로팅 버튼 없음. 기능부터 바로.
- 아이콘은 선 아이콘(stroke 1.8, 24 viewBox), 인라인 SVG. 이모지 금지. 예외: 홈 판매·구매 아이콘은 2톤 일러스트 (아래 규격).

## 색 (라이트)

| 토큰 | 값 | 용도 |
|---|---|---|

| `ink` | `#24123A` | 본문 글자 |

| `ink-3` | `#8E80A3` | 캡션, 시간, placeholder |
| `line` | `#DED2EA` | 카드·입력 테두리 |

## 글꼴

| 역할 | 글꼴 | 굵기 |
|---|---|---|
| 본문·제목 | Noto Sans KR (next/font/google) | 400 / 500 / 700 |
| 숫자·가격·모델명 | IBM Plex Mono, `tabular-nums` | 500 / 600 |

크기 단계 (px): 11 캡션 · 12 보조 · 13 본문(목록) · 14 본문 · 15 강조 · 17 검색 입력 · 18 로고 · 20 제목.
줄 간격 1.5. 한글 `word-break: keep-all`.

## 간격·모양

- 간격 스케일: 4, 6, 8, 10, 12, 16, 20, 24, 28.
- 페이지 옆 여백: 데스크톱 24, 모바일 16.
- 모서리: 입력·버튼·카드 6, 타일 10, 아이콘 원 12, 로고 마크 6.
- 테두리 1px `line`. 검색창만 2px `primary`.
- 그림자 없음 (시안 뷰어 제외).

## 브레이크포인트

| 이름 | 폭 | 홈 배치 |
|---|---|---|
| 모바일 | < 768 | 세로 1열. 하단 탭바. 실시간은 데스크톱과 같은 두 줄(가로 스크롤) |
| 태블릿·데스크톱 | ≥ 768 | 문구·검색·판매/구매 아이콘(최대 폭 880), 구매대행·경매 자리(높이 80, 점선 — 기능 미정이라 비워 둠), 실시간 구매요청·판매매물 두 줄(최대 폭 1200)을 한 덩어리로 세로 가운데, 사이 간격 24. 화면·배율이 커져도 배치·간격은 그대로, 배경만 넓어짐 |

## 컴포넌트 규격

**타일 큐 (화면 분할)** 모든 화면 전환을 하나의 큐로 (스펙 `docs/superpowers/specs/2026-10-01-tile-queue-design.md`). 폭 768 이상만 분할: 1칸 전체 → 2칸 1:1 → 3칸 왼쪽 1/2 · 오른쪽 위 1/4 · 오른쪽 아래 1/4 (읽는 순서 = 오래된 순서, 새 칸은 오른쪽 아래, 가득 차면 왼쪽 칸이 빠지고 당겨짐). 칸 사이 구분은 없음(각 칸 배경). 2칸 이상이면 모든 칸 오른쪽 위에 닫기(28 원, 흰 배경, 1px `line`, 호버 `primary` 테두리). 로고는 항상 홈 전체화면.

**헤더** 높이 56 (모바일 52). 배경 `primary`, 글자 흰색, 내비 `on-primary`. 로고 = 초록 사각(28, radius 6) + 흰 칩 아이콘 + "커널마켓" 18/700. 오른쪽 로그인(텍스트) · 회원가입(초록 버튼 34px). 로그인·회원가입은 **별도 페이지**로 이동 (모달 아님). 헤더는 루트 레이아웃에 한 번만 두고, 로그인·가입 화면과 분할(2·3칸) 상태에서도 같은 링크를 유지한다 (로그인 상태면 그 자리에 닉네임·로그아웃).

**검색** 높이 56 (모바일 44). 흰 배경, 2px `primary` 테두리, radius 8. 왼쪽 카테고리 `select`(112px, `primary-soft` 배경 — 카테고리 마스터 미정으로 보류, 지금은 숨김) · 돋보기 · 입력 17px · 오른쪽 검색 버튼(104px, `primary`, 흰 16/700). 아래 "인기 검색" 텍스트 링크 한 줄, 중앙 정렬. 최대 폭 880 (아이콘 줄과 같은 칸). 위에 한 줄 문구(20/700, 모바일 17, 중앙). 히어로가 아니라 한 줄이 전부.

**홈 판매·구매 아이콘** 카드·글씨 없이 아이콘만. 두 묶음을 한 줄에 (모바일은 두 줄). 묶음 앞 배지: 높이 24, radius 5, 12/700, 판매 `primary`·구매 `green` 채움 + 흰 글자 ("판매"·"구매").
- 아이콘 48 (모바일 40), 48 viewBox 2톤 일러스트: 연한 면(`primary-soft`/`green-soft`) + 진한 선(stroke 2, `primary`/`green`) + 오른쪽 아래 꽉 찬 배지 원. 이름은 툴팁(`title`)·`aria-label`로만. 호버 시 배경 radius 12: 판매 `primary` 10%, 구매 `green` 12% 반투명 (`-soft` 토큰은 페이지 배경과 거의 같아 호버가 안 보임).
- 판매 4: 판매상품 등록(메뉴: 직접 입력 · 파일 추가 엑셀/PDF/이미지) · 판매상품 다량 등록(엑셀 선택창 바로) · 판매정보 추가 등록 · 판매 견적 조정.
- 구매 3: 상품검색·견적 요청 · 견적 확인 · 엑셀 대량구매(엑셀 선택창 바로).
- 메뉴는 흰 배경 + 1px `line`, 그림자 없음. 파일 검사 결과는 아이콘 줄 아래 한 줄 (오류 `down`, 안내 `ink-2`, 닫기 ×).

**실시간 목록** 구매요청·판매매물을 한 줄씩 (사용자 지시: 아래로 쌓지 않고 옆으로). 제목줄: 점(7px, 종류색) + 제목 14/700 + "전체 ›" 링크. 아래로 작은 카드(폭 224, 흰 배경, 1px `line`, radius 6, 안쪽 10/12, 호버 `primary` 테두리)가 옆으로 이어지고 줄 안에서 가로 스크롤(snap). 카드: 제목 13/500 말줄임 · 가격(mono 12/600) · 등록자(사업자=`primary-dark`, 개인=`ink-2`) · 카테고리·수량 · 오른쪽 끝 시간(`ink-3`). 줄 높이는 카드 하나로 고정이라 페이지는 세로 스크롤 없음.

**검색 결과 화면** (`/search`, 스펙 `docs/superpowers/specs/2026-10-01-search-results-design.md`) 칸 폭 기준(`@container`)이라 타일 칸이 768 미만이면 모바일 배치(접힌 필터·작은 검색창). 단 결과 표↔카드만 기준이 576 — 반반 분할(칸 720 안팎)에서도 표가 가로로 펼쳐진다 (사용자 지시). 홈 | 결과 같은 분할은 화면이 아니라 타일 큐 엔진이 맡는다 (decisions.md 2026-10-01 타일 큐). 결과 영역 최대 폭 1200, 스크롤 허용 (홈 "스크롤 없이" 원칙의 예외). 위에서부터:
- 검색창: 홈 검색창 모양, 높이 48 (모바일 44). 왼쪽 select는 검색 구분 전체/상품명/제조사 (112, 모바일 72). 인기 검색 줄 없음.
- 필터 바: 흰 배경, 1px `line`, radius 6, 안쪽 12. 카테고리(보류 중이라 숨김) · 거래상태 3칸 토글(선택 칸 `primary-soft`/`primary-dark`) · 재고 · 가격 범위 · 납품일 · 초기화(텍스트) · 적용(`primary` 34). 입력 높이 34. 모바일은 [필터 (n)] 버튼(높이 40)으로 펼침.
- 결과 머리줄: "검색결과 N건 · M개 선택" + 견적 요청(outline `primary`) · 구매(`primary` 채움), 34. 선택 0개면 비활성.
- 결과 표(데스크톱): 흰 카드. 머리 행 40 `bg` 배경 12/500 `ink-2`, 행 44, 구분선 `line-2`, 호버 `bg`. 열 14개(체크 포함, 항목·순서는 스펙 — 사용자가 정한 그대로)라 표 최소 폭 1336, 카드 안 가로 스크롤. 체크·상품명은 왼쪽 고정(`sticky`, 상품명 오른쪽 구분선 `line-2`). 상품번호·날짜 mono. 데이터시트·사진은 선 아이콘 18, 상품설명·대체품·테스트리포트·정품인증서는 유무만 ○(`primary`) / ✕(`ink-3`). 불량지원은 '대체'·'환불' 글자. 거래완료 행은 `ink-3` + '거래완료' 뱃지(`line-2`/`ink-2`).
- 결과 카드(모바일): 체크 · 상품명 14/500 · 제조사·상품번호 12 · 상태·수량·단가 + 아이콘 · 있는 보증·서류만 칩(높이 20, `primary-soft`/`primary-dark` 11/500). 선택하면 탭바 위에 견적 요청·구매(40) 바가 붙음.
- 결과 상태: 로딩은 행 높이 44 스켈레톤 8줄, 오류는 "불러오지 못했어요"(429면 "잠시 후 다시 시도해 주세요") + [다시 시도]. 다음 페이지가 있으면 목록 아래 가운데 [더 보기](outline 34), 실패하면 받은 결과는 두고 버튼 옆 오류 한 줄. "검색결과 N건"은 전체 개수.

**매물 상세** (`/listings/{userId}/{regDate}`, 스펙 `docs/superpowers/specs/2026-10-02-listing-detail-design.md`) 흰 카드 3개를 위에서 아래로: 상품 상세 내역 · 데이터시트 · 사진. 카드 안쪽 16 (모바일) / 24.
- 상세 내역: 제목 상품명 22/700 + 상품번호 mono 15 `ink-2` + 거래완료 뱃지, 아래 사양 한 줄 13 `ink-2`. 왼쪽 큰 사진(320 정사각, `object-contain`, 없으면 선 아이콘, 위쪽 정렬 — 표 높이로 늘어나지 않음) · 오른쪽 정보 표(라벨 112 `ink-2`, 행 구분선 `line-2`, 빈 값 `–` `ink-3`). 칸 1024 이상이면 표는 라벨·값 두 쌍을 한 줄에 (사용자 지시: 전체 화면에서 빈 곳이 많았다). 행 순서는 사용자가 준 화면의 항목(제조사·상품코드·리드 타임·상태·단가·수량)이 먼저, 나머지 컬럼이 뒤. 표 아래 버튼 34: 구매자 견적 요청(outline)·구매(채움), 판매자 수정(outline)·삭제(채움). 맨 아래 구분선 뒤 제품 개요(줄바꿈 유지).
- 데이터시트: PDF 뷰어 높이 640 (모바일 480) + 바로 아래 "새 탭에서 열기"(iframe 안 PDF를 못 그리는 모바일 브라우저용), 그 아래 서류 링크(테스트리포트·정품인증서·대체품, 없으면 `–`). 비로그인은 "로그인 후 열람" + 로그인 링크.
- 사진: 4열 (모바일 2열) 정사각 `object-cover`, 누르면 원본 새 탭.
- 칸 폭 `@md` 미만이면 사진과 정보 표를 위아래로 쌓는다.

**매물 등록 폼** (`/listings/new`, 스펙 `docs/superpowers/specs/2026-10-02-listing-create-design.md`) 폼 페이지 규격 + 최대 폭 720, 흰 카드 하나. 구역 3개(상품 정보 · 판매 조건 · 설명·파일)는 카드 대신 구분선(`line-2`) + 제목 15/700. 칸 폭(`@md`) 이상이면 짧은 칸 2열, 미만이면 1열.
- 상품상태: [신품][중고] 2칸 토글(높이 44, 선택 `primary-soft`/`primary-dark`) + 중고면 "신품대비 [__] %" 숫자 칸(폭 80).
- 숫자 칸 mono `tabular-nums`. 단가 아래 `formatPrice` 결과를 `ink-3` 보조 문구로.
- 사진: 정사각 칸 4개(데스크톱 4열, 좁으면 2열, 간격 8). 빈 칸 점선 `line` + 이미지 아이콘 + "사진 추가". 채운 칸 오른쪽 위 닫기(28 원, 타일 닫기 모양), 첫 칸 "대표" 뱃지(뱃지 규격 `primary-soft`/`primary-dark`). 업로드 중이면 사진 50% + 스피너.
- 데이터시트: [PDF 선택] outline `primary` 34 + 파일 이름(말줄임) + ×.
- [등록] 44 `primary` 전체 폭. 업로드 중에도 비활성.

**모바일 하단 탭바** 높이 60. 홈 · 매물 · 등록(`primary` 원 40) · 내 정보. 활성 `primary`, 비활성 `ink-2`. 글자 10px.

**버튼** 기본 34px, 큰 것 40. `primary` 채움+흰 글자 / 초록 채움+흰 글자 / 텍스트. 비활성은 40% 투명.

**뱃지** 높이 20, radius 5, 11/600. 사업자 `primary-soft`/`primary-dark`, 개인 `line-2`/`ink-2`.

## 폼 페이지 (로그인·가입)

- 헤더 유지. 본문은 `bg` 배경에 흰 카드 하나 중앙 배치, 최대 폭 420 (기업 가입 폼 560), 안쪽 24 (모바일 20). 카드 위 제목 20/700, 아래 보조 13 `ink-2`.
- 입력 높이 44, 라벨 13/500 `ink-2` 위에. 상태 테두리: 기본 `line` → blur 후 오류 `down`, 통과 `up`. 오류 문구 12 `down` 입력 아래.
- 주 버튼 44 `primary` 전체 폭. 보조 링크(찾기·가입) 13 `ink-2`, 가운데 `·` 구분.
- 소셜 버튼 44, 브랜드 색 그대로: 카카오 `#FEE500`/검정 글자, 네이버 `#03C75A`/흰 글자, 구글 흰 배경+`line` 테두리. 로고는 브랜드 마크 인라인 SVG (선 아이콘 규칙 예외).
