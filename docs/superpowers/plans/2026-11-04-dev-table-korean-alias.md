# 임시 테이블 엑셀 불러오기: 정의서 논리명(한글) 별명 (2026-11-04)

## 설계
사용자 지시(상무님이 테스트에 쓰심): 엑셀 시트 이름·1행 컬럼명을 정의서의 **논리명(한글)** 으로 써도 불러와진다. 물리명도 그대로 받는다(둘 다 인정). DB 테이블·컬럼 이름은 바꾸지 않는다 — 별명은 불러올 때 물리명으로 바꾸는 매핑일 뿐이다. 로컬 전용 도구(`APP_ENV=local`)라 운영 경로 없음.

### 매핑 (`DevTableAliases`, `devtools` 안 한 파일)
- 원본: `KPIT-BRK-테이블정의서.xlsx`(2026-10-27 14:08 판, 저장소 밖)의 "테이블명 (논리)"·"컬럼명 (논리)". 정의서 글자 그대로 쓴다 — 오타도 그대로(`시용자ID`, `개업년원일`, `일렬번호`) (사용자 결정 2026-11-04).
- 키는 **현재 DB 컬럼 이름**. 정의서가 물리명을 `REG_DATE` 로 겹쳐 적은 칸(`prov_date`·`prod_date`·`prod_reg_date`·`seller_id` 등)도 논리명(제공가능일·상품등록일시·판매자ID …)은 서로 달라서 이어진다.
- `trd_prod_master.prod_mufc_date` 는 정의서에 없다. 별명을 만들지 않는다 — 물리명으로만 받는다 (사용자 결정 2026-11-04, 필요 없음).
- 비교는 공백을 모두 무시하고(정의서에 "등록 일시"·"사용자 명"처럼 띄어쓴 이름이 있다) 대소문자도 무시한다. 한 테이블 안에서 별명끼리, 별명과 물리명끼리 겹치면 테스트가 실패한다.

### 동작
- 시트 이름: 물리명(`trd_user_info`) 또는 논리명(`사용자 정보`). 모르는 이름이면 지금처럼 "시트 이름이 테이블이 아닙니다" 로 전체 거절.
- 1행: 컬럼 물리명 또는 논리명. 모르는 이름은 지금처럼 거절. 한 컬럼이 물리명·논리명으로 두 번 나오면 지금의 "컬럼이 두 번 나옵니다" 로 거절.
- 불러오기 이후(값 변환·삽입·롤백)는 그대로. API 경로·응답 그대로 → Bruno 요청 변경 없음.
- 범위 밖: 임시 화면(표 보기)의 컬럼 제목은 그대로 물리명. 요청에 없어서 뺐다(필요하면 따로).

### 영향 검토
- 바뀌는 곳은 `DevTableService` 의 `importAll`(시트 찾기)·`importSheet`(헤더 찾기)뿐. 조회·생성·수정·삭제·연쇄 삭제는 그대로.
- 프론트 변경 없음(같은 엔드포인트, 화면 문구에 헤더 규칙 설명 없음 확인).
- 정의서가 바뀌면 이 표도 같이 고친다(`DevTableRelations` 와 같은 방침).
