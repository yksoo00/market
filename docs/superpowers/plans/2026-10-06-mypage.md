# 마이페이지·헤더 사용자 메뉴 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 로그인 후 헤더를 아바타 메뉴(마이페이지·로그아웃)로 바꾸고, `/my` 에서 내 판매글을 본다.

**Architecture:** `/api/v1/listings/mine` 응답에 가격·수량·상태·대표 사진을 더한다(기존 필드 유지). 프론트는 `Header` 의 로그인 후 영역을 `UserMenu`(shadcn DropdownMenu)로 분리하고, `/my` 는 `RequireLogin` 안에서 `MyListings`(커서 [더 보기])를 그린다. 쓰기 API·인증 변경 없음.

**Tech Stack:** Spring Boot 4.1 + MockMvc/Testcontainers, Next.js 16 + React 19, Tailwind 4(컨테이너 쿼리), shadcn `DropdownMenu`, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-06-mypage-design.md`

## Global Constraints

- 브랜치 `feat/mypage` 하나, 푸시 후 PR. 로컬 머지 금지. 사용자의 untracked `docs/setup.md` 는 스테이징하지 않는다(경로를 명시해 `git add`, CRLF 파일은 `git -c core.autocrlf=false add`).
- 새 의존성 없음(shadcn `dropdown-menu` 는 이미 있음).
- 개인정보(이메일·전화·실명)는 응답·화면에 넣지 않는다. 메뉴 맨 위는 닉네임 + 개인/사업자 배지만.
- 사용자에게 보이는 문구는 `frontend/src/messages/my.ts` (헤더 메뉴 문구 포함). 컴포넌트에 하드코딩 금지.
- 가격은 `formatPrice()` 로만, 사진은 `<img>` + `fileUrl(key)` + 해당 줄 lint 예외 주석(`lib/files.ts`).
- 커밋 trailer `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`, PR 본문 끝 `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.
- 프론트·백엔드 검증: `./gradlew check`(Docker 필요), `pnpm typecheck && pnpm lint && pnpm test`.
- 메뉴 항목은 [마이페이지], [로그아웃] 둘뿐. 설정·내 정보 관리 항목은 만들지 않는다.

## Review Focus

1. 닉네임이 이모지·한글·앞뒤 공백·빈 문자열일 때 이니셜 한 글자가 깨지지 않는다 → Task 2 `initialOf` 테스트.
2. 레거시 매물은 단가·수량이 null 일 수 있다. API 는 null 을 그대로, 화면은 "가격 제안"/빈 칸으로 → Task 1 null 테스트, Task 3 `formatPrice` 기본값.
3. 거래완료 글과 사진 없는 글이 목록에서 구분·대체 표시된다 → Task 1 `tradeStatus`/`photo` null 테스트, Task 3 배지·자리 아이콘.
4. 로그아웃이 실패하면 메뉴가 닫히며 오류가 사라지지 않는다 → Task 2 (실패 시 메뉴 유지 + `role="alert"`).
5. 닉네임이 아주 길어도 헤더·메뉴가 깨지지 않는다 → Task 2 말줄임(`truncate`), 브라우저 체크리스트.
